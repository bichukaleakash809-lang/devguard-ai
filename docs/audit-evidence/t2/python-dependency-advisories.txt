STARLETTE, PER ADVISORY — the one package genuinely in the request path
-----------------------------------------------------------------------
  PYSEC-2026-1943  multipart form fields buffered without a size limit
  PYSEC-2026-1941  large multipart files mishandled
  PYSEC-2026-249   request.form() limits not enforced for urlencoded bodies
      -> All three require multipart/urlencoded form parsing. This API is
         JSON-only: no route declares Form/File/UploadFile, and
         `pip show python-multipart` reports "Package(s) not found", so
         Starlette cannot parse multipart at all in this install.

  PYSEC-2026-161   Host header not validated when reconstructing request.url
  PYSEC-2026-248   request path not validated when reconstructing request.url
      -> Both trigger through `request.url`. Nothing in backend/ reads
         request.url, base_url, or url_for. NOTE: this is the pair most likely
         to become reachable — any future route that builds a URL from the
         request would light it up.

  PYSEC-2026-2281  StaticFiles UNC-path SSRF, Windows only
      -> StaticFiles is never mounted, and deployment targets are Linux.

  PYSEC-2026-2280  HTTPEndpoint method dispatch via getattr
      -> All routes are function-based (@router.get/@router.post). No
         HTTPEndpoint subclass exists.

CONCLUSION, STATED CAREFULLY
----------------------------
Every one of the 56 is unreachable **given the code as it stands today**. That is
a statement about this application's current shape, not a clean bill of health
for the dependencies: they are real vulnerabilities in shipped packages, and the
starlette request.url pair in particular would become reachable the moment a
route reconstructs a URL.

NOTHING WAS CHANGED. Contract §13.1 forbids dependency changes without explicit
approval, and the standing instruction for this session repeats it.

RECOMMENDATION FOR THE OWNER, in priority order
-----------------------------------------------
1. Drop `aiohttp==3.9.1`. Nothing imports it; it contributes 30 of the 56
   advisories and zero functionality. Lowest-risk, highest-reduction change
   available.
2. Bump `starlette` (via a compatible `fastapi`) — the only package in the
   request path. `fastapi==0.104.1` pins starlette 0.27.0; a modern fastapi
   brings starlette >= 0.40 and clears the whole multipart class plus the
   request.url pair. Needs the API surface re-verified: 209 tests, verify_otel.py,
   and the five frontend routes.
3. Resolve `chromadb` / `sentence-transformers` (open issue 4). Both are
   unimportable already; removing them also removes the transformers advisories
   and ~5.4 GiB of install.
4. `protobuf` and `python-dotenv` bumps are low-risk but also low-value here,
   since neither advisory's entry point is called.

CI now runs pip-audit and npm audit on every push, report-only. See the comment
block in .github/workflows/ci.yml for why it does not gate.
